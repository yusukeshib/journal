## 経験

### Fable
*2019年 - 現在 / ニューヨーク州ニューヨーク市 / チーフアーキテクト、プリンシパルソフトウェアエンジニア*

- Fable は、ビデオ、グラフィック、またはアプリ内 (Lottie) 用のアニメーションを作成するためのブラウザベースのモーション デザイン ツールです。Fable には 35 人の従業員、20 人のエンジニア、60,000 人を超えるユーザーがいます。( Crunchbase )
- チーフアーキテクトとして、フロントエンド、バックエンド、Web アセンブリ、タスク処理インフラ、OpenGL ベースのレンダラーなどの主要なシステムを設計および実装しました。
- 柔軟で拡張可能な製品構造と、ユーザーが再利用可能で複雑な視覚効果機能を構成できるファイル形式を設計しました。
- レンダリング パイプライン、シェーダー システム、WebAssembly 統合を含む Rust ベースのレンダリング エンジンを主導しました。
- 高可用性を備えた 10,000 インスタンスの同時実行をサポートする、高度にスケーラブルな GPU タスク (アニメーション フレーム生成およびサムネイル/プレビュー生成用) 処理サーバー構造を設計および実装しました。
- Stable Diffusion と Python を使用してAI 視覚効果機能の開発を主導しました。
- Stripe ベースのサブスクリプション/支払いシステムを実装するプロジェクトを主導しました。

### Gakko
*2017 - 2019 / 東京、日本 / エンジニアリング リード、ソフトウェア エンジニア*

- Gakko は、子供向けのアニメーションストーリーブックを制作および販売するプラットフォームでした。
- NodeJs を使用した Rest API サーバーと Github CI + AWS 上のデプロイメント システムを使用してバックエンドを設計および実装しました。
- 複数のプラットフォーム向けにReactとReact-Nativeを使用してフロントエンドUIアプリを設計および実装しました
- Web および iOS (Objective C) 用の React-fiber を使用してキャンバス レンダラーを設計および実装しました。
- デジタルチームを率いて、私たちが実装した製品は投資家を引き付け、エンジニアリングチームは私の次の会社であるFableにスピンアウトしました。

### Semi-transparent design
*2003 - 2017 / 東京、日本 / エンジニアリング リード、ソフトウェア エンジニア*

- C、C++ を使用してインタラクティブなコードを記述することで、多くのアート インスタレーションに携わり、多くのアーティストを支援しました。
- JAXA宇宙センターウェブサイト：JAXAの科学者が作成した膨大な文書を整理するプロジェクトを主導し、WIKI構造に基づいた組織システムと管理ウェブアプリを実装しました。
- LeoLeoni インタラクティブ展示: 有名な絵本「スイミー」にインスピレーションを得て、OpenGL、WebCam を使用した Mac OS アプリを使用したインタラクティブな空間インスタレーションを企画、管理、構築しました。
